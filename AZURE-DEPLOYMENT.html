Why Container Apps

The monitor runs all the time and handles little traffic, so the cost is small and fixed.

No servers to manage

Azure runs the container. No virtual machine to patch, and no Docker host to keep alive.

Small fixed cost

One 0.25 vCPU, 0.5 GiB replica. The monthly free grant covers part of its compute.

Same image as local Docker

The image is built on your PC and pushed to Azure, so what runs in Azure is what you tested.

Reuses what exists

The script reuses any resource already in the resource group, and creates only what is missing.

Azure architecture

Everything sits in one resource group. The app talks to ServiceNow, Teams and email over HTTPS. Data is stored in Blob Storage, not on the app.

The SWAT board runs inside the same app. The public address is HTTPS on port 443, and the app listens on port 8080 inside the container.

Deploy steps

Run these from the P1-api-monitor folder. The full details are in README-powershell.md.

  1. Install the requirementsAzure PowerShell (Install-Module Az -Scope CurrentUser) and Docker Desktop, running.
  2. Fill in .envCopy .env.example to .env. Set SN_INSTANCE, SN_CLIENT_ID and SN_CLIENT_SECRET. Leave the storage connection string empty on a first run.
  3. Run the scriptpowershell -ExecutionPolicy Bypass -File .\deploy-azure.ps1. Sign in with the device code shown.
  4. Copy the storage connection stringIf the script created a storage account, it writes storage-connection.txt. Copy its AZURE_STORAGE_CONNECTION_STRING line into .env, save, and press Enter.
  5. Wait for the build and pushThe image is built on your PC and pushed to the registry. The environment takes a few minutes to appear.
  6. Open the SWAT boardThe script prints the https:// address. Check the log in the portal under Monitoring > Log stream.
Security: the SWAT board has no login. Add -AllowedIpRange with your office or VPN range, for example -AllowedIpRange 203.0.113.0/24, so only that network can open it.

Security and cost safeguards

Secrets

The OAuth client secret and the storage connection string are Container Apps secrets, not plain values.

Network

With -AllowedIpRange, only that address range can reach the app.

Registry

The admin user is on for simplicity. Turn it off and use a managed identity if your policy requires it.

One replica

Only one copy runs, so alerts are not sent twice and the data files are not written by two copies.

Where the money goes, and how to lower it

  • The registry is about 53% of the bill. GitHub Container Registry can host the image at no charge. The script uses Azure Container Registry, so switching means changing the script.
  • Keep one replica, and do not scale to zero. Scaling to zero would stop the 15-minute checks.
  • No Log Analytics. The script creates the environment without a log destination, so there is no workspace to pay for.
  • Delete the resource group when the monitor is no longer needed. Everything in it stops being billed.
  • Free account: a new Azure free account includes about USD 200 of credit for 30 days. Azure for Students includes credit without a card.
